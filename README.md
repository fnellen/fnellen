<h1 align="center">Hi 👋, I'm Federico</h1>

I build software for people and stay involved when the software goes live. My work spans backend development, React-based interfaces, CI/CD and self-hosted infrastructure.

## Selected work

- **[ViaPlot](https://viaplot.com)** — An EU-hosted platform for interactive storytelling maps. I work on the product and its infrastructure, including Cloudflare and observability with Grafana.
- **Europe Magazine** — A custom editorial workflow and CMS developed with the team around the way its newsroom works. I maintain the application and its infrastructure, from code to VPS.
- **[UniFi Voucher Printer](https://github.com/fnellen/unifi-voucher-printer)** — A Flask and Next.js application that connects a hotel reception's workflow to its UniFi network and label printer. It runs on a Raspberry Pi.
- **[Softwareentwicklung im Team](https://github.com/fnellen/software-entwicklung-im-team)** — A Spring Boot team project that documents how we applied domain-driven design, test-driven development and accessibility to a real application.

## What I work with

**Web and backend:** React, Next.js, Astro, Tailwind, Python, Flask, Django, Java and Spring Boot  
**Delivery and operations:** Docker, Docker Swarm, CI/CD, Linux VPS, Cloudflare and Grafana  
**How I work:** Stakeholder collaboration, testing, domain modelling and accessibility

Currently exploring Next.js and Docker Swarm in more depth.
